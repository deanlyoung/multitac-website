Getting started

Start a TAC

A TAC is an editable notebook where prose and calculations share one source. Start blank, choose an Inspiration example, open a supported text document, or begin with a guided TIQ.

# Weekend gathering
Planning pizza with friends.
people = 6
slices = people * 3
pizzas = ceil(slices / 8)

walk = 3.5 km
walk in miles

Results appear beside the source at wide widths and below it on compact screens. Editing people recalculates slices and pizzas.

Writing and syntax

  • Use # for a heading and // to force a line to be a note.
  • Plain sentences and Markdown-style bullets remain notes.
  • Use = for explicit, case-sensitive variables.
  • Functions use parentheses and comma-separated arguments.
  • Exponentiation is right-associative. -2^2 means -(2^2).
  • Results display ten significant digits by default.

Variables and dependencies

Variables are sequential and local to the notebook. Derived definitions retain their formulas. When an input changes, Multitac recalculates all affected dependents transitively.

  • A dependency cycle produces a diagnostic.
  • A broken input invalidates affected results instead of preserving stale values.
  • A unit name cannot be reused as a variable.
  • Blank lines separate total groups. Bare sum, total, avg, and average summarize the preceding group.
  • prev resets at a blank line or calculation error.

Built-in functions

Function names are case-insensitive. Aggregate functions accept values, arrays, variables, and nested arrays. Compatible units are preserved.

Compatibility names

Apple and Excel names that perform the same scalar or array calculation share an implementation. TAC keeps choose(n, r) for combinations; selection uses pick(index, values…). Dotted names such as STDEV.P and VAR.S are accepted.

Units and conversions

Addition and conversion require compatible dimensions. Products and quotients preserve dimensional meaning. Offset temperatures cannot be multiplied as ordinary quantities.

distance = 12 km
distance in miles

speed = 65 mi / hour
time = 3.5 hours
speed * time in km
  • Angles default to radians; explicit deg works in any angle setting.
  • Volume units use US customary definitions.
  • CSS units use 96 pixels per inch and 16 pixels per em.
  • Decimal data prefixes use 1000; binary prefixes use 1024.

Equations and collections

Equations are sequential and document scoped. A bare unknown can be rearranged from a prior equation. solve(name) stores a solution, and named arguments can evaluate it. Two-by-two numeric matrix systems are supported.

Arrays and integer ranges work with sum, prod, map, and reduce. Named iterators such as a=1..3 stay local to the call.

scores = [12, 18, 24]
average(scores)
stdev.p(scores)

sum(x^2, x=1..10)

Dates and time

Dates use the device’s local time zone unless an IANA time zone is specified. Date durations use fixed seconds: a day is 24 hours, a year is the mean Gregorian 365.2425 days, and a month is one twelfth of that year. They are not calendar-aware month additions.

launch = date("2027-04-12")
daysbetween(date("2027-01-01"), launch)
launch in "Europe/London"

Cards, pins, and live results

  • Input cards edit a source literal through a bounded range. Bounds and step can be changed while keeping the current value valid.
  • Comparison cards track any two calculated lines.
  • Plot cards visualize a numeric collection or bounded integer range as a live one-series line plot.
  • Pins preserve a reference to a stable source-line identity.
  • Mac and Apple Vision Pro can open supported results in separate live windows or panels.

Cards never become a second copy of the value. They retain source references and refresh from evaluation.

TIQ workflow

A TIQ (Thought Invoking Question) is a question-led way to create or continue a TAC. Guided, curated, and Personalization TIQs use deterministic app-authored questions. Open-ended TIQs use Apple’s on-device model where available. Both paths can gather a goal, assumptions, preferences, and constraints, then propose visible source.

  1. Choose a focused goal or exploratory path.
  2. Answer in conversation, or edit the TAC directly.
  3. Review proposed prose and expressions.
  4. Apply, revise, or discard the proposal.
  5. Undo accepted edits as ordinary document changes.

AI can draft source, but CalcCore evaluates every accepted expression. Redo replays the accepted source rather than invoking the model again.

Memory and Insights

Memory indexes notes and successful results from TACs opened on the current device. It does not crawl unrelated files or scan unopened iCloud documents.

  • Search remembered entries and insert a visible copy with a source comment.
  • Exclude an individual notebook.
  • Forget entries, clear all local Memory, or pause learning.
  • See source links and last-seen dates.

Find connections uses Apple’s on-device Foundation Model when available. It receives a bounded selection of current and related entries, treats notebook text as data, and returns suggestions with permitted source IDs. Those references are validated before display. A valid reference does not prove the interpretation is correct, so generated prose remains a suggestion to review.

AI limitations

Before Multitac first sends notebook material to Apple’s on-device model, it explains these limits and records only a local, non-identifying acknowledgement on that installation.

  • AI suggestions may be incomplete or wrong.
  • A citation identifies material supplied to the model; it does not prove the interpretation is correct.
  • CalcCore evaluates separately displayed arithmetic. That calculation does not validate the surrounding generated prose or advice.
  • Review assumptions, units, source, expressions, and results before relying on or applying generated content.
  • Multitac does not provide financial, legal, medical, engineering, tax, investment, emergency, or other professional advice.

Model-driven proposals remain visible until you apply, revise, or discard them. Accepted source remains editable and can be undone like an ordinary document change. Canceling the disclosure leaves deterministic TIQs, manual editing, and calculation available without invoking the model.

Documents and sync

The native .mtac document is regular UTF-8 text. An optional JSON footer stores stable line IDs, settings, pins, cards, the notebook Memory preference, and TIQ history. Multitac hides that footer in the editor and can recover readable source if metadata is absent or damaged.

iCloud Drive transports documents through Apple’s document infrastructure. Multitac has no custom sync server or remote account database.

Current limits

  • Currency and cryptocurrency calculations are deliberately unsupported.
  • English input is supported for the first release.
  • There is no cloud AI fallback, collaboration service, remote account, rich-text attachment system, or native ink canvas.
  • The current plot card is a single-series line plot.
  • Calendar months and years are fixed-duration calculation units, not calendar-aware additions.
  • Some capabilities depend on Apple’s on-device model availability.
