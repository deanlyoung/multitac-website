The source stays visible

A notebook first.
A calculator throughout.

A TAC keeps prose, assumptions, expressions, and results in one editable document. The calculation engine is deterministic, and the document remains the source of truth.

01

Write without switching modes

Mix headings, notes, variables, equations, units, lists, and dates. Multitac recognizes calculations while ordinary sentences stay ordinary sentences.

02

Change one assumption

Dependent values recalculate through the notebook. Cycles and broken inputs invalidate affected results instead of leaving stale answers behind.

03

Make values interactive

Turn inputs into editable range cards, compare two calculated lines, or plot a numeric collection. Every card still points back to source.

Two ways into the same document

Compose a TAC.
Begin with a TIQ.

Direct writing and guided conversation meet in the same editable .mtac document. You can move between them without changing formats.

TAC

Think directly on the page

A TAC is the living notebook itself: freeform text, calculations, results, cards, pins, and context together.

  • Edit source at any time
  • See live results beside or below it
  • Keep calculations deterministic
  • Open portable text formats in place

TIQ · Thought Invoking Question

Let a question shape the page

A TIQ gathers goals, values, and constraints, then proposes visible TAC source for review. Accepted changes become ordinary edits with Undo.

  • Choose goal-directed or exploratory guidance
  • Review, revise, apply, or discard proposals
  • Keep manual editing authoritative
  • Let CalcCore evaluate every expression

One capability set, four native expressions

Made for each screen it runs on.

Multitac shares its documents and core capabilities across Apple products while adapting navigation, density, input, and window behavior to each one.

iPhone

A compact library, push navigation, and a current-result bar that keeps editing focused.

iPad

Sidebar browsing, adaptive side-by-side work, keyboard support, and document windows.

Mac

A full library, tabs, menu commands, Undo and Redo, and separate live result windows.

Apple Vision Pro

Comfortable native windows, separate result panels, and system scene restoration.

Insights with boundaries

Calculation first. Suggestions second.

Multitac uses Apple’s on-device model where available to suggest connections from a bounded set of notebook entries. Generated prose stays separate from calculated results.

On deviceNo cloud AI service, API key, or remote Multitac account.
Source backedSuggestions cite the notes and displayed values supplied to the model.
ReviewableTIQ proposals stay visible until you apply, revise, or discard them.
User controlledMemory can be paused, excluded per notebook, forgotten entry by entry, or cleared.

Broad calculation support

Everyday arithmetic to dimensional models.

The language covers reactive variables, percentages, equations, collections, scientific and statistical functions, units, dates, and time zones. Currency and cryptocurrency are deliberately outside the first release.

Math & statistics

Aggregates, variance, correlation, combinatorics, logic, trigonometry, logarithms, roots, and rounding.

Units & dimensions

Compatible conversion, dimensional products and quotients, temperatures, data units, and CSS units.

Equations & collections

Sequential equations, reverse solving, arrays, integer ranges, map, reduce, sum, product, and 2×2 systems.

Dates & time

ISO dates, durations, Unix time, date differences, local time, and named IANA time zones.
