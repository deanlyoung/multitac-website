Support

Find the source of the problem.

Start with the guide for syntax and feature behavior. If something still looks wrong, include the platform, the relevant TAC source, and the result you expected.

Read the documentation

The Multitac documentation covers calculation syntax, built-in functions, units, equations, dates, cards, TIQs, Memory, Insights, documents, and current limits.

Before reporting a calculation

  1. Copy the smallest TAC excerpt that reproduces the result.
  2. Include the displayed result or diagnostic.
  3. Say what you expected and why.
  4. Include your Multitac version, product, and system version.

Please remove private names, notes, or values before sharing a TAC excerpt.

Portable documents

Multitac opens Markdown, Calca, and Numi files as UTF-8 text. Rich cards, pins, stable line metadata, Memory preferences, and TIQ history are native .mtac features and are not embedded into portable formats.

Known boundaries

  • Currency and cryptocurrency calculations are unsupported.
  • Insights and model-driven TIQs require an available Apple on-device model.
  • Memory learns only from notebooks opened on the current device.
  • Cross-device document transport depends on iCloud Drive and your Apple Account settings.

Report a problem

For an incorrect calculation, harmful AI suggestion, document-loss concern, privacy or security issue, accessibility barrier, or intellectual-property concern, include the app version and build, platform, a minimal redacted example, the result you expected, and what occurred. About in the app shows the version and build.

Share only the smallest excerpt needed to reproduce a problem. Do not send a complete private notebook when a redacted expression or screenshot is sufficient.

Contact

Email support@multitac.app. Do not attach a private notebook unless you have removed information you do not want to share.
